# Timéo OS — Portfolio

Un portfolio personnel déguisé en **vieux bureau Windows rétro** (95/98),
entièrement fait main dans **un seul fichier HTML**.

**➡️ Voir le site : [tsolma15.github.io](https://tsolma15.github.io/)**

---

## Le concept

Tout le site tient dans un unique `index.html` : **zéro framework, zéro
dépendance, zéro fichier externe**. Les sons sont synthétisés en Web Audio et
les icônes sont dessinées en SVG pixel-art directement dans la page. On y
retrouve des fenêtres déplaçables, un menu Démarrer, un gestionnaire des tâches,
un Démineur jouable… et quelques secrets cachés pour les curieux.

## Fonctionnalités

- 🖥️ Bureau interactif : fenêtres déplaçables et redimensionnables, barre des
  tâches, menu Démarrer, Aero Snap, sélection lasso
- 🌗 Mode sombre, police adaptée à la dyslexie, 3 tailles de texte
- 🌍 Multilingue **FR / EN / IT**
- 🧩 Démineur, gestionnaire des tâches, terminal, et des easter eggs à dénicher
- ♿ Respecte `prefers-reduced-motion` ; réglages mémorisés localement

## Sous le capot

`HTML` · `CSS` (variables thémables) · `JavaScript` vanilla · `Web Audio API` ·
`SVG` inline · hébergé sur **GitHub Pages**.
